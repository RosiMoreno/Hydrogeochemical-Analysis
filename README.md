# Hydrogeochemical Analysis

This repository contains Python scripts and Jupyter notebooks developed for the processing, visualization, and interpretation of hydrochemical data from groundwater and thermal water systems.

The project combines automated data processing workflows with hydrogeochemical interpretation techniques commonly used in groundwater and geothermal studies.

---

## Objectives

- Process hydrochemical datasets efficiently using Python.
- Automate repetitive calculations and data transformations.
- Generate publication-ready hydrochemical diagrams.
- Support groundwater and thermal water characterization.
- Assess water-rock interaction processes and hydrogeochemical evolution.

---

## Python Workflows

The scripts included in this repository allow:

- Import and preprocessing of hydrochemical datasets from Excel files.
- Conversion of concentrations from mg/L to meq/L and mol/L.
- Calculation of ionic ratios.
- Automatic generation of hydrogeochemical diagrams.
- Export of figures and processed datasets.

### Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Hydrogeochemical Interpretation

The workflow incorporates several approaches commonly used in hydrogeology and geothermal studies.

### Water-Rock Interaction Assessment

Evaluation of dominant geochemical processes such as:

- Carbonate weathering
- Silicate weathering
- Evaporite dissolution
- Groundwater mixing processes

### Hydrogeochemical Diagrams

#### Gaillardet Diagram

Assessment of geochemical evolution through the relationships:

- HCO₃⁻ / Na⁺
- Ca²⁺ / Na⁺

Used to identify the dominant water-rock interaction processes.

#### Na/Cl versus SiO₂

Evaluation of:

- Silicate alteration processes
- Deep hydrothermal contributions
- Groundwater residence time indicators

#### Cl/Br Relationships

Assessment of groundwater origin and salinity sources through molar chloride-bromide ratios.

Potential interpretations include:

- Continental recharge waters
- Evaporite dissolution
- Saline groundwater inputs
- Deep circulation systems
